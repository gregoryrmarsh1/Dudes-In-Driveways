Community Chat

Stay connected between driveway gatherings by chatting with fellow Dudes! We recommend using a third‑party chat service such as Minnit Chat, which you can embed into this page by copying a few lines of code. This cloud‑hosted solution allows members to talk without leaving the site and can be customised to match our colour scheme.

To set up the chat:

  1. Visit the chosen chat service (for example, Minnit Chat) and create a new chatroom.
  2. Follow the provider’s instructions to customise your chat and copy the embed code provided.
  3. Replace the placeholder below with your embed script.

Chat widget will appear here once you paste the embed code.
